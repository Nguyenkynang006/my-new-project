# Hệ thống CRM Chăm sóc Khách hàng

Đồ án thực hành môn Triển khai và Quản trị Hệ thống Phần mềm.

## Mục tiêu

Xây dựng ứng dụng CRM quản lý khách hàng, người liên hệ và lịch sử tương tác; triển khai bằng Docker Compose với PostgreSQL, pgAdmin, Nginx, Prometheus, Grafana, Loki và Promtail.

## Trạng thái

Repository đang ở giai đoạn chuẩn bị. Hướng dẫn cài đặt, cấu hình môi trường, khởi chạy và địa chỉ demo sẽ được cập nhật sau khi tích hợp ứng dụng.

## Bảo mật

- Không commit file `.env`, mật khẩu thật, token hoặc private key.
- Dùng `.env.example` để mô tả các biến cần thiết, không đưa secret thật vào file mẫu.
